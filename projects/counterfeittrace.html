The problem

Counterfeit goods can enter legitimate supply chains through many small and unusual transactions. CounterfeitTrace models the network as a transaction graph and searches it for patterns associated with high risk.

01 / GRAPH

Sellers, buyers, and products become connected entities

02 / MODEL

A GraphSAGE model learns unusual selling patterns

03 / INTERFACE

A 3D view helps explain network risk visually

The system

01

Model transactions

Represent synthetic supply-chain activity as a graph suitable for machine learning.

02

Score anomalies

Train and test GraphSAGE on transaction behaviour that may indicate counterfeit entry points.

03

Visualise risk

Present connected entities and risk scores through an explorable React and Three.js interface.
